## 💼 What I do at work

- **Media mix modeling.** Built Adobe Acrobat's MMM from zero, run globally (NA, EMEA, Japan, APAC, UK). Built a Bayesian MMM at DMA level with Google Meridian for Popeyes. Its optimizer guided second-half local media spend.
- **Causal measurement.** Double ML and survival models for CRM impact. Geo lift tests on the agency side.
- **ML in production.** Store-level demand forecasting (LightGBM), a multi-armed bandit for offers, customer segmentation.
- **Making it usable.** Dashboards and an AI chatbot on Snowflake Cortex so teams can query loyalty data themselves. Results presented to VPs, directors and the CMO.
